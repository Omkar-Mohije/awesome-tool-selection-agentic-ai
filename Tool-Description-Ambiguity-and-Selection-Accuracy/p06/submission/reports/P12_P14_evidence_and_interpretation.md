# P12–P14: contribution, real-output evaluation and interpretation

**Chosen pathway:** a resource-constrained descriptive prompt comparison plus reproduction of an existing diagnostic metric. It continues the review's distinction between tool choice and downstream execution. It does not require an original algorithm or publication novelty. The paper's empirical contribution is its actual model/task observations and transparent debugging/measurement analysis, with scope proportional to evidence.

**Completed development evidence:** task successes original/general/checklist 0/6 each; 13 first state mismatches, four response mismatches and one force termination across the 18 records. Strict no-call 0/11 available decoded intervention records, one unavailable. Published decision score on two eligible missing-parameter pairs: 50%, 25%, 75%; post-hoc and not proof of improvement. Author-reference/dispatch controls are software evidence and never included in model accuracy.

**Evaluation code:** `scripts/analyze_run.py` checks all manifest hashes, completed generation/evaluation status, exact unique result IDs, serving exceptions, header counts and case failures before computing CSVs/plots. It was executed on the authentic recovery ZIP. Files in `results/development` and their figures contain genuine values only. New prospective outputs have no table until supplied. Published diagnostic code and source locks are in the linked original diagnostic folder.

**Interpretation:** full-task floor effects coexist with measurable decision differences. Possible explanations include long-horizon state tracking, wrong-directory actions, prompt instructions too weak to govern behavior, and metric target differences. The data do not isolate those mechanisms. Lower-level correct calls or decision attempts are not the same as a successful task. The primary prospective metric is frozen independently of hoped-for results.

**No more than three follow-ups:** (1) complete the already frozen fresh evaluation, highest immediate value; (2) later compare matched-length instructions with family-level splitting to address prompt/order confounds; (3) add another affordable model or independently evaluated clarification quality after revisiting resource and label feasibility. Do not run these later follow-ups automatically or tune on the frozen evaluation and relabel it unseen.
