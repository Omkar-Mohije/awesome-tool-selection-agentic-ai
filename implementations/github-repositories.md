# GitHub Implementations

Five existing repositories chosen for documentation quality, active maintenance, and direct connection to a research paper or recognized benchmark.

- **[OpenBMB/ToolBench](https://github.com/OpenBMB/ToolBench)** — Official implementation and dataset release for ToolLLM (ICLR'24 Spotlight); trains and evaluates LLMs for large-scale tool selection over 16k+ APIs.
- **[ShishirPatil/gorilla](https://github.com/ShishirPatil/gorilla)** — Official repository for Gorilla and the Berkeley Function-Calling Leaderboard; includes retriever-aware fine-tuning code and the BFCL evaluation harness.
- **[sierra-research/tau-bench](https://github.com/sierra-research/tau-bench)** — Official τ-bench implementation; runnable retail/airline environments plus an auto-error-identification script that classifies whether a failure was "wrong tool" vs. "wrong argument."
- **[microsoft/JARVIS](https://github.com/microsoft/JARVIS)** — Official implementation of HuggingGPT, using an LLM controller to select among specialized models hosted on Hugging Face as if they were tools.
- **[philschmid/ai-agent-benchmark-compendium](https://github.com/philschmid/ai-agent-benchmark-compendium)** — Actively maintained compendium of 50+ agent/tool-use benchmarks, categorized by capability (function calling, reasoning, coding, computer use); useful for tracking the fast-moving benchmark landscape.
