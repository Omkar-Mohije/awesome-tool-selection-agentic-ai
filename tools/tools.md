# Tools and Libraries

Five frameworks/libraries used to build and study multi-tool agentic systems.

- **[LangChain](https://github.com/langchain-ai/langchain)** — General-purpose framework for composing LLM calls, tools, and agents; the most widely used harness for prompting-based tool selection.
- **[LlamaIndex](https://github.com/run-llama/llama_index)** — Data-aware agent framework with ReAct-style reasoning and a Workflows engine for orchestrating multi-step tool use over document/data sources.
- **[CrewAI](https://github.com/joaomdmoura/crewAI)** — Multi-agent orchestration framework where agents can be assigned distinct tool sets and roles, relevant to multi-agent tool-sharing scenarios.
- **[Hugging Face smolagents](https://github.com/huggingface/smolagents)** — Lightweight library where agents select tools by writing and executing Python code rather than emitting structured JSON calls.
- **[OpenBMB BMTools](https://github.com/OpenBMB/BMTools)** — Open-source tool-learning framework for building and plugging in ChatGPT-plugin-style tools for LLM agents.
